## ルート

- 問題演習：本文＋設問を表示し、全設問と4択をまとめて表示。回答を選び直してから一括採点し、全設問の正誤と正解を表示。
- 要約：同じ本文全体を日本語・英語で要約。主題・重要な内容・正確さ・簡潔さを各3点で評価。良い点、改善点、英語の誤り（英語回答のみ）、要約例を返す。点数は学習用で英検公式の採点ではない。

下書きは級・長文・言語別にブラウザー内へ保存。リトライノートのデータには触れない。生徒の入力とAI出力はHTMLとして実行せずテキスト表示。

## API

`https://eiken-title.onrender.com/api/reading/summary` へ `{passage_id,language:'ja'|'en',summary}` をPOSTする。本文はクライアントから受け取らず、バックエンドに保持する同じIDの本文を使用。既存 eiken-title のGeminiキーをサーバー側で利用し、ブラウザーに秘密鍵を置かない。

`passages.json` はフロントエンド・バックエンドで同一内容にする。解答は既存の公式PDF解答184問と、以前に取得した解答キー342問から照合。画面には解答出典を表示しない。

検証：`node --test tests/reading-data.test.js`。

長文一覧に「演習済み」「要約済み」を個別表示。演習は全問の一括採点時、要約はGeminiの正常なフィードバック取得時に完了として記録。得点にかかわらず取り組み完了を保存する。以前の演習完了記録も引き継ぐ。完了記録はこのブラウザー内に保存され、ページを閉じても保持する。
