# Release version

For every user-visible update, increment the patch number once before publishing (for example, 1.8.1 → 1.8.2). Use a version explicitly requested by the user instead when provided. Keep the visible version in index.html and APP_VERSION in version-badge-v176.js synchronized. Update the entry-point cache query so returning users receive the release. Internal follow-up fixes in the same unpublished update share that release number.
